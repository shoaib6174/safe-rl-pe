## Work Done

### Critical Bug Fix: Capture Counting in Evaluation
- **File:** `repro_gonultas_isler_2024/evaluation/evaluate.py:99-100`
- **Bug:** `if ep_reward > 0:` undercounts captures because episode reward can be negative even when capture occurs (step penalties accumulate)
- **Fix:** `if step < env.max_steps:` — episode ended before max_steps means capture occurred
- **Impact:** CR values increased significantly (e.g., seed0 ep11000 selfplay went from ~0.49 to 0.55)
- Also applied fix on niro-2 via sed
