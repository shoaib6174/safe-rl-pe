### Bug Fixes Discovered During Testing
1. **vectorized_env.py frame_stack=1 bug**: `-(self.frame_stack - 1)` with `frame_stack=1` evaluates to `-0` which in Python is `0`, so `list[0:]` returns the entire buffer instead of empty. Fixed with explicit `frame_stack == 1` branch.
2. **train.py hidden_dim not passed**: `MADDPGAgent` was constructed without `hidden_dim`, silently defaulting to 128 regardless of config. Fixed by passing `hidden_dim=config["maddpg"]["hidden_dim"]`.
3. **Population duplicate adds**: `completed_episodes % pop_add_freq == 0` was true on every step once reached. Fixed with `last_pop_add_ep` tracker.

## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Actor-only population | MADDPG update only needs opponent_actor; BiMDN belief is env-level during rollout |
| Standalone Pop-FSP (not combined with EMA) | Cleaner ablation; paper presents vanilla → EMA → Pop-FSP as three distinct methods |
| Uniform sampling first, PFSP later | Baseline strategy; PFSP as secondary ablation if needed |
| FIFO eviction | Simplest; can swap for diversity-based later |
| `last_pop_add_ep` tracker | Prevents duplicate population adds on every step after checkpoint boundary |
