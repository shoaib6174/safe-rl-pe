## Work Done

### Root Cause Analysis
Identified structural asymmetry in Pop-FSP training:
- Pursuer trains with `∃` quantifier: catch ANY evader from population → easy
- Evader trains with `∀` quantifier: escape ALL pursuers from population → hard
- Uniform sampling + abrupt warmup switch exacerbates the problem
- Wrote detailed analysis: `repro_gonultas_isler_2024/results_pop_fsp/BALANCE_ANALYSIS.md`

### Implementation

#### PopulationManager (`training/population_manager.py`)
- Added `episodes_added` tracking per member
- Added `sample_recency(current_episode, lambda_decay)` method with exponential decay weights
- Added `_load_actor(idx)` helper to reduce code duplication
- Updated `save()`/`load()` to preserve episode metadata

#### Training Loop (`training/train.py`)
- Added config support for asymmetric populations (`pop_evader_size`)
- Added recency-biased sampling (`pop_recency_lambda`)
- Added gradual mixing schedule (`pop_mixing_start`, `pop_mixing_end`)
- Replaced hard warmup cutoff with probabilistic mixing ratio
- Population additions now record episode number

#### New Config (`config_pop_fsp_v2.yaml`)
```yaml
pop_size: 8               # pursuer population
pop_evader_size: 16       # evader population (2x)
pop_recency_lambda: 0.15  # exponential decay bias
pop_mixing_start: 100     # start mixing at ep 100
pop_mixing_end: 500       # full population by ep 500
```

## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Recency-biased sampling instead of full PFSP | No win-rate tracking infrastructure; recency is cheap approximation of "opponents at similar skill level" |
| Asymmetric populations (16 vs 8) | Compensates for evader's structural disadvantage (`∀` vs `∃`) |
| Gradual mixing (ep 100-500) instead of hard warmup | Prevents early lock-in to equilibrium before population diversity kicks in |
| λ=0.15 for recency decay | Tuned for 8-member population: ~60% weight to most recent half |
| 3 seeds (0,1,2) for first test | Fast iteration; will expand to 4-5 if promising |

**Verdict: Tier 1 (recency + asymmetric + gradual) FAILED.** Seeds 1/2 locked to CR=1.0 by ep 660 — *earlier* than v1 baseline (ep 1500). Structural `∀/∃` asymmetry is too strong for sampling tweaks.

**Decision:** Kill v2 runs, pivot to **Option C** — cap population mixing at 80% (`pop_mixing_max=0.8`) so agents always see 20% current opponent. Never reaches 100% population sampling.
