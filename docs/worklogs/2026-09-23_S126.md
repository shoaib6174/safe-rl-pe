## Work done

### 1. Retrospective — `docs/retrospective_2026-09-23.md`

Built from D1–D132. Five phases: self-play stabilisation (8 mechanisms, structural failure known
since D37), the pe2 rebuild (infrastructure, no claims), the learner problem (8 rounds, all
refuted, then D108 showed the whole chain followed a diverging critic), shielded games (13 rounds,
all re-scoped by D125), the rebuild (D126–D132, correct but scooped).

**Six causes named.** The largest: we gated inference and never gated meaning — four times a
carefully measured quantity did not mean what we named it (D108, D125, D126/D130, D129), and in
every case the statistics were impeccable and the construct was wrong. Then: the apparatus
improved while the question stood still; we answered hard problems with new tools rather than
changing the problem; clean negatives accumulated and none was ever treated as the finding;
the feedback loop was days long while the decisive check took one viewing; crowded field, no
differentiating asset.

**Corrective rule, now binding:** nothing is interpreted before its construct is validated
behaviourally. That gate would have caught four of the five collapses within a day each.

### 2. Plan — `docs/pathway/ral_plan_boundary_condition_2026-09-23.md`

Headline moves from the diagnosis to the contradiction. Pizarro Bejarano et al.
(arXiv:2410.11671) report that penalising filter interventions **helps**; D129 found it **hurts**.
The reconciling condition is where the task reward has gradient. Four components (S18 boundary
experiment, S19 second environment, S20 proposition, S21 write-up), with the crossover
pre-registered as the kill condition. Estimated RA-L acceptance moves ~1 in 5 → ~2 in 5.

### 3. Pre-registration — `docs/pathway/boundary_condition_prereg_2026-09-23.md`

Two corrections made **before any number exists**:

- **The plan's independent variable was wrong.** "Reward density" is not the claim. `w_vis` is
  dense everywhere yet flat inside the pocket (the evader is invisible there), so density and
  gradient-on-`I` come apart. Design is therefore **2×3**: `{BASE, PEN} × {SPARSE, DENSE-FLAT,
  DENSE-VARY}`, with DENSE-FLAT as the discriminating cell.
- **The penalty had to be theirs.** D129 penalised stalled steps; they penalise the magnitude of
  the filter's correction, every step. Round implements `-λ‖a_nom − a_safe‖`.

**Amendment A1** (same day, before any arm): disjoint streams (calibration 1 860 000+, construct
1 880 000+, probe 1 950 000+, gate 1 900 000+ — the original text collided calibration with the
gate); **both dense weights calibrated** to equal expected per-episode return so the columns
differ in gradient location and nothing else; evaluation built unwrapped.

reference capture 0.350 reproduces the D109 random-search floor to three decimals; 0 violations.

| DENSE-FLAT | 1.097e-08 | **2 / 148 (1.4 %)** |

**CG1 failed** — the column is not flat. Bar not moved; the pre-registered consequence (rename) was
taken: DENSE-FLAT -> DENSE-RARE, with CG1's measured coverage carried in `COLUMNS` so code and paper

capture to 0, because the fixed intercept law plays whenever the learner has nothing to act on, and it
won 2/50. Specification error, not a result. Corrected in the open; the 0.040 floor is disclosed.

**New blocking check** on any column whose BASE arm cannot clear the 0.350 floor (w_search calibrates
~20x above D4's patrol-not-hunt level), stated for all three columns so it cannot be invoked
