## Context

Following the failure of warm-start BR and RecurrentPPO, we pivoted to a fundamentally different approach: explicit belief-state self-play using a particle-filter belief tracker instead of the masking curriculum. The hypothesis is that the curriculum's distributional shift (p_full_obs 1.0→0) creates an exploitability hole. By providing consistent belief-based observations from the start, the policy learns to reason under uncertainty natively.

## Work Done

### Task 1: BeliefTracker Implementation (`envs/belief_tracker.py`)
- Particle filter with 100 particles, uniform weights
- **Visible**: resample particles around true opponent position with σ=0.2m
- **Hidden**: diffuse particles with σ = v_max * dt * sqrt(steps_since_seen), clamped to arena bounds
- **Output**: 6-D statistics [mean_x, mean_y, std_x, std_y, entropy, time_since_seen]
- dt = 0.05s (corrected from initial spec error of 0.1s)

### Task 2: PartialObsWrapper Integration (`envs/partial_obs_wrapper.py`)
- Added BeliefTracker instance in `__init__` with role-aware opponent v_max
- `reset()` calls `belief_tracker.reset()`
- `_build_obs_dict()` updates tracker and appends belief to return dict
- Observation space now includes `"belief"`: Box(shape=(6,))

### Task 3: Policy Network Belief Branch (`agents/partial_obs_policy.py`)

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| **No masking curriculum for BELIEF_s200** | Belief provides consistent obs under pure PO from start; curriculum creates distributional shift that causes exploitability. |
| **Process noise σ = v_max * dt * sqrt(steps)** | Scales with time hidden and opponent max speed. Square root accounts for diffusion (random walk variance grows with t, not t²). |
| **Belief in NavigationEnv (always "visible" goal)** | Ensures obs space matches PartialObsWrapper so weights transfer at micro-phase transition. |
| **Conditional belief in OpponentAdapter** | Old models don't have "belief" in obs space. Hard failure (KeyError) without this check. |
| **dt = 0.05s** | Actual PursuitEvasionEnv timestep. Spec initially said 0.1s — caught during spec review. |
