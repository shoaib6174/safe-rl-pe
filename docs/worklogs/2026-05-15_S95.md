## SP17 Post-Mortem (Completed ~3h later)

**Status:** All 3 seeds completed 20K episodes.

**Critical finding — SECOND actor observation bug discovered:**
The target Q computation in `maddpg.py:119-120` had the same bug as the actor update:
```python
next_actions_p = self.actor_target(next_obs_p)
next_actions_e = other_agent.actor_target(next_obs_e)
```
When `self` is the evader, `next_actions_p` uses the **evader's** actor on pursuer obs (should use pursuer's actor), and `next_actions_e` uses the **pursuer's** actor on evader obs (should use evader's actor). The actions are **swapped**.

**Impact:**
- Evader critic loss (EC) exploded to 10^14–10^15
- Evader actor loss (EA) exploded to 10^7–10^8
- Pursuer losses stayed reasonable (~200-400)
- Capture rate stuck at 1.000 for all seeds at end
- **Entire SP17 run is INVALID** — critic targets were computed with wrong actions

**Fix applied (commit 066aa3d):**
```python
if agent_id == "pursuer":
    next_actions_p = self.actor_target(next_obs_p)
    next_actions_e = other_agent.actor_target(next_obs_e)
else:
    next_actions_p = other_agent.actor_target(next_obs_p)
    next_actions_e = self.actor_target(next_obs_e)
```

## SP17-Rev Post-Mortem (Re-launched with target Q fix)

**Status:** Re-launched with target Q fix. Early logs showed PC≈EC and PA≈EA (balanced, no explosions).

**Critical finding — THIRD bug: Evader trained on pursuer reward:**
In `maddpg.py:107`:
```python
rewards = torch.FloatTensor(batch["rewards_p"]).unsqueeze(1).to(self.device)
```
The evader's critic was trained on `rewards_p` (pursuer's reward) instead of `rewards_e` (evader's reward). In a zero-sum game, this means the evader was trained to **maximize the pursuer's return** — i.e., to get caught.

**Impact:**
- Evader actor loss was positive (same sign as pursuer) — it was trying to help the pursuer
- Capture rate stayed at 1.000 — evader was literally trained to be caught
- **Entire SP17-rev run is INVALID** — evader learning wrong objective

**Fix applied (commit bc5edbd):**
```python
rewards = torch.FloatTensor(batch["rewards_p" if agent_id == "pursuer" else "rewards_e"]).unsqueeze(1).to(self.device)
```

**SP17-rev2 smoke test after reward fix:**
- PA = +115.8 (positive, pursuer maximizing its reward)
- EA = −112.2 (negative, evader maximizing its own reward = negative of pursuer's)
- PC ≈ EC (balanced, same magnitude)
- CR = 0.000–0.250 — evader now learning to escape!
