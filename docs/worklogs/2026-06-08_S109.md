## Work Done

### Shared Policy Diagnosis
- Checked niro-2 logs: all 3 seeds collapsed to unilateral lock-in
  - Seed 0: CR=0.000 (evader-dominant) at ep 4672
  - Seed 1: CR=1.000 (pursuer-dominant) at ep 8380
  - Seed 2: CR=0.000 (evader-dominant) at ep 4261
- **Root cause identified**: Separate critics with different value scales create gradient imbalance. When one role dominates, its critic trains on high-value trajectories (Q~10,000) while the dominated critic trains on rare trajectories (Q~1,000). The shared actor receives a strong signal from the well-trained critic and a weak/noisy signal from the poorly-trained critic. Well-trained critic wins → lock-in amplifies.
- The negative feedback mechanism fails because it assumes both critics are equally accurate. They are not.

### PBT Implementation
- Created `PBTTrainer` class in `training/train_pbt.py`:
  - Population of 5 `SharedMADDPGAgent` instances (each with role-conditioned actor + separate critics)
  - Random agent pairing per env during training
  - Shared replay buffer (all agents contribute, random agents update)
  - Periodic tournament evaluation (round-robin, 10 games per matchup)
  - Weakest agent replaced by mutated copy of strongest (Gaussian noise std=0.01)
  - Optimizer state reset on replacement
- Created `config_pbt.yaml` with PBT-specific hyperparameters
- Created `eval_pbt.py` for population round-robin analysis
- Created `launch_pbt.sh` for niro-2 deployment

## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Use shared actor (role-conditioned) within PBT | Already implemented; PBT adds diversity at population level, not parameter level |
| No EMA in PBT | Population diversity provides natural exploration; EMA adds complexity without clear benefit |
| Replace only actor weights + critics (no replay buffer clear) | We want the new agent to benefit from population experience |
| Reset optimizer state on replacement | Prevent stale momentum from carrying over |
| Mutation std=0.01 | Subtle perturbation; strong enough to explore, weak enough to preserve good policies |
| Tournament every 1000 episodes | Frequent enough to respond to meta-game shifts, not so frequent that agents don't learn |
