### Paper Verification (2405.05372)
Read pages 1–10 of the downloaded PDF. Verified hyperparameters match our config:
- Arena 16×16m, capture radius 0.15m, max steps 400 ✓
- MADDPG: 20K episodes, 8 parallel envs, buffer 100K, batch 512, lr=0.0005, γ=0.99, τ=0.005 ✓
- BiMDN: 1-layer BiLSTM (128 hidden), 32 features, 3 components, history 200, downsample 10 ✓
- Curriculum: FOV decay + evader velocity increase over T/10 episodes ✓
- **Discrepancy found**: Paper wheelbase l_f = l_r = 0.15m → total L = 0.30m. Our code used L = 0.15m (half).
- **Discrepancy found**: Paper curriculum ends at T/10 = 2000 episodes. Our config used t_end_ratio=0.3 → 6000 episodes.
- Paper cites [40] Ackermann et al. "Reducing overestimation bias in multi-agent domains using double centralized critics" — strongly suggesting twin critics are used.

### Root Cause Analysis: NaN Losses

**GI-v2-amp (BiMDN + AMP):** NaN losses starting at episode 177, 83.7% NaN rate.

| Test | Result |
|------|--------|
| Raw beliefs [-8,8] vs normalized obs [-1,1] | **Scale mismatch** — beliefs 8× larger |
| Fix: divide beliefs by arena_size/2=8 | Reduced but did not eliminate NaNs |
| **No-AMP test (500 ep)** | **CR=1.00, zero NaNs** → AMP is a trigger, not root cause |
| Full no-AMP run (20K ep) | **NaN at ep 15802** → AMP accelerates a deeper instability |

**Evader critic loss before NaN:**
```
ep15790: EC = 1,956,107,958,353,920  (1.9 quadrillion)
ep15798: EC = 2,205,154,589,802,496
ep15802: EC = nan
```

Root cause: **Single-critic MADDPG overestimation bias** — positive feedback loop in target Q update.

Self-play is severely pursuer-dominated. The evader cannot develop escape strategies against our trained pursuer.

### Fix 1: Gradient Clipping
Added `clip_grad_norm_(..., max_norm=1.0)` to all 4 gradient paths (critic/actor × AMP/non-AMP).

**Result:** Delayed explosion but did not stop it. Evader critic reached 210M at ep 9500.

### Fix 2: Double/Twin Critics
Implemented twin critics per Ackermann et al. (2019), matching the paper's cited technique:
- `critic2` + `critic2_target` + `critic2_optimizer` per agent
- Target Q = `reward + gamma * min(target_q1, target_q2)`
- Both critics updated each step; both targets soft-updated

**Result:** 20K episodes completed with **ZERO NaNs**. Max EC loss bounded at 25,819.

However, evaluation still showed pursuer dominance (CR=0.994 self-play, 0.602 vs random).

### Fix 3: Wheelbase & Curriculum Discrepancies
- **Wheelbase**: Changed `L` from 0.15 → 0.30 in `envs/pursuit_evasion_env.py`. Also made env read wheelbase from config instead of hardcoded default. Updated all configs.
- **Curriculum duration**: Changed `t_end_ratio` from 0.3 → 0.1 in `config_belief_noamp.yaml`.

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| **Disable AMP for BiMDN runs** | AMP triggers NaN cascade in BiMDN+MADDPG. Vanilla MADDPG tolerates AMP fine. BiMDN run without AMP is stable. |
| **Implement twin critics** | Paper cites Ackermann et al. 2019. Single-critic MADDPG suffers from overestimation bias → Q-value explosion. Twin critics directly address this. |
| **Fix wheelbase to 0.30m** | Paper specifies l_f = l_r = 0.15m → total L = 0.30m. Our L=0.15 made pursuer turn 2× faster, causing dominance. |
| **Shorten curriculum to 2000 ep** | Paper uses T/10 = 2000 episodes. Our 6000 ep gave pursuer 3× more full-FOV training time. |
| **Evaluate at pre-NaN checkpoint** | Checkpoint 15750 is healthy (CR=1.00 training). Evaluation reveals generalization gaps vs paper. |
