### PBT dual-role balance selection verification
- Inspected `repro_gonultas_isler_2024/training/train_pbt.py`:
  - `evaluate_tournament()` computes both `pursuer_wr` (how often agent i captures) and `evader_wr` (how often agent i escapes).
  - `balance_score = -|pursuer_wr - 0.5| - |evader_wr - 0.5|` — higher means more balanced in BOTH roles.
  - `replace_least_balanced()` replaces the agent with the lowest balance score by a mutated copy of the agent with the highest balance score.
- Config matches intent: `population_size=5`, `replacement_freq=500`, `tournament_games=10`, `mutation_std=0.01`.
- Training loop calls `evaluate_tournament()` then `replace_least_balanced()` every 500 episodes.
- **Verdict: code is correctly wired for dual-role balance selection.** Runtime confirmation must wait until episode 500 tournament output.
