## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Periodic forced switch every 3M steps | SP16e ran 23M steps (76 phases) with single forced switch at 3M — longest stable co-evolution. Prevents freeze-sticking where one role trains indefinitely. |
| Search reward w_search=0.0001 | S84 trajectory analysis showed systematic search is a critical missing skill. Staleness-based grid reward teaches area coverage without hard-coding patrol. |
| 4-seed validation (42-45) | S73 established CUDA non-determinism dominates. Single seed is a gamble. 4 seeds minimum for robust validation. |
| Keep equal speeds 1.0/1.0 with 20×20 arena | SP16g config — best converged run. Speed advantage caused degenerate behavior (pure speed strategy, no PE dynamics). |
| Forced switch must check every micro-phase | Discovery during smoke test: inside eval block meant check only every 150 micro-phases. Moved to per-micro-phase check. |
