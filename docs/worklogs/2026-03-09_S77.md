| Decision | Rationale |
|----------|-----------|
| **Kill all SP12 runs** | All 8 declining, 3m omni sensing too restrictive (2.8% arena coverage). SP13 already 2x better at half the steps. |
| **FOV 90° + 8m is the primary config** | SP13a peaked at 93-97% CR — far more learnable than 3m omni. Realistic for camera-based mobile robot. |
| **Test 5m range (SP13c/d)** | Interpolates between failed 3m and successful 8m. Determines minimum viable sensing range. |
| **Alternate freeze threshold 0.6** (SP13e-h) | SP13a/b show pursuer hits 60%+ quickly. Lower threshold enables earlier co-evolution before pursuer overspecializes. |
| **Asymmetric obs for SP13g/h** | Evader with full obs is the most adversarial realistic setup — tests if pursuer can learn against an opponent that always sees it. |
