Exception is deletable in one command and fully documented inline. |
| D94: negative-control collapse criterion requires three conditions: non-empty judging window, control fails pass rule, upper CI < 0.137 | Collapse is claimed only when statistical separation is demonstrated: (1) the judging window is non-empty, (2) the control fails the pass rule, (3) the upper end of the CI on its final win rate lies below 0.137. This three-part test distinguishes genuine collapse from control merely dipping under bound (e.g., 0.020 final → upper ~0.050 certifies collapse; 0.130 final → upper ~0.184 does not). When collapse cannot be claimed, the runner refuses to report survivors, writes the reason in words to the results file and figure, and exits non-zero (non-zero exit = rerun needed, not crash). This criterion prevents goalpost-moving (D83). |
