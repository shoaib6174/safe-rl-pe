## Pre-registration amendments (fix wave, 2026-09-04, before any pilot ran)

Nothing here was changed after seeing a pilot result — no pilot has run. Each
item is a change to the pre-registration recorded with its reason, per D83.

| # | Amendment | Reason |
|---|-----------|--------|
| A1 | **Training seeds narrowed to one shared seed for the three off-policy arms**: P-A / P-B / CTRL all use **seed 7** (was 7 / 8 / 10); P-C keeps **seed 9**. | The training seed drives critic initialisation, exploration noise and the training env's episode stream, so one seed per arm confounds the mechanism under test with between-seed variance — measured at 0.010–0.280 across weight seeds under an identical protocol in this project (D68–D74 cohort). Paired, the three off-policy arms differ only in mechanism. P-C is a different algorithm family (PPO: no replay buffer, no critic warm-up, its own BC clone) and cannot be paired with them, so pairing it would suggest a comparison that does not exist. |
| A2 | **A pass for P-B additionally requires the anchor divergence to have GROWN** across the probes (`arms.PB.anchor.kl_grew is True` in `t0_pilots.json`). | The pass rule is "does not collapse". An actor the anchor pins to the clone satisfies it *by not moving*: it sits at the clone's rate at every probe and would be reported as the sole survivor, sending Tier 1 to spend weeks on an expensive way to preserve a clone. `train/anchor_kl` is the one measurement separating "the anchor stopped harmful drift" from "the anchor froze the policy"; it is now stamped onto every P-B probe row. **`pilot_passes` itself is unchanged** — the bound and the collapse criterion are not touched — so this condition is applied by the reader at the direction table, with the number and a worded verdict in the results file next to `pass`. |
| A3 | **P-C's verdict is forced to `null` (undetermined) when its own BC clone was too weak to be judged**: when the Wilson upper bound on its measured starting win rate falls below 0.137, `arms.PC.pass` is `null` with `pass_reason` in words, and P-C cannot appear in `survivors`. | P-A / P-B / CTRL start from the gated clone, which is where the 0.137 bound comes from. P-C starts from a freshly trained PPO clone of unknown quality and was judged against the same bound: a weak start would have been reported as a refuted horizon hypothesis with the contradicting number buried in the file. Same pattern as the D94 control verdict — a null with a reason, never a bare failure. |
| A4 | **The anchor weight sweep is narrowed from β ∈ {0.1, 1.0} (derisk v2 T0.3) to β = 1.0 only.** | Budget: the tier buys one 200k GPU arm per *mechanism*, and a second β is a second point on the same mechanism rather than a fourth diagnosis. Recorded rather than done silently. The narrowing is only safe together with A2: with one β and no divergence readout a P-B pass would have had no interpretation. If P-B passes with a divergence that grew only marginally, or fails with a divergence that never moved, β = 0.1 is the pre-committed follow-up before Tier 1 uses the anchored chassis. |
| A5 | **The T0.2 plateau check is applied per term, not to the summed dense reward**, and each term gets the check the spec states for it: indicator terms (`vis`, `evis`) keep the 0.05–0.95 band on the positive fraction; continuous terms (`search`, `pbrs`) are checked for non-constancy (std > 0 and no single value on ≥ 95 % of steps). | The band was only ever exercised on the visibility term alone. On the configuration that actually trains (`w_vis=0.1` + `w_search=1e-4`) the **sum** reads a positive fraction of 0.971 and fails the band, purely because search-staleness is non-negative by construction (mean staleness of the observed cells; zero only when nothing is visible). A positive fraction across terms on different scales is not interpretable, and the band is not the criterion a non-negative continuous term is owed — the spec's own check for that term is "staleness must be non-constant along a random trajectory". **The band was not widened.** Gate result on the shipped configuration, 6211 clone steps, seed 790500 (`results/derisk/t0_nondegeneracy.json`): `vis` positive fraction 0.072 (passes), `search` modal fraction 0.495 over ~700 distinct values (passes). The gate now runs before P-A trains and the runner exits if a term fails. |
| A6 | **Signal-audit seed stream extended**: `790500+` is reserved for the T0.2 plateau-gate rollout, and `signal_audit` seeds torch's global generator from its own `seed0`, recorded as `torch_seed`. | The stochastic regime is the training-time regime the kill rule speaks about and it drew from an unseeded global generator, so the headline number was not reproducible from the seed the report recorded (two calls at the same `seed0`: visible fraction 0.0348 vs 0.0258). |
