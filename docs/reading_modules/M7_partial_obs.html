7.1 From MDP to POMDP

A Markov Decision Process (MDP) assumes the agent observes the full state s at every timestep. A Partially Observable MDP (POMDP) relaxes this: the agent only observes o ~ Ω(o | s), where Ω is the observation distribution.

Why POMDPs Are Harder

In an MDP, the optimal policy is a function of the current state: π*(s). In a POMDP, the agent must maintain a belief b(s) — a distribution over possible states — and act on that belief: π*(b).

The belief update (Bayes filter) is:

$$b_{t+1}(s') = \eta \cdot \Omega(o_{t+1} | s') \sum_s T(s' | s, a) \cdot b_t(s)$$

where T is the transition model, Ω is the observation model, and η is a normalizing constant.

Insight: Computing the exact belief update requires knowing the transition and observation models. In deep RL, we don't have these models — so we must either (1) learn them, (2) approximate the belief, or (3) use memory (RNN/LSTM) to implicitly track history.

The G&I Sensing Model

The G&I 2024 environment uses:

  • Pursuer: FOV 120° (2π/3 rad), range 6m
  • Evader: Omnidirectional (2π rad), range 1000m (effectively infinite)

This asymmetry is intentional: the evader has better situational awareness, which partially compensates for its lower speed.

7.3 Belief States

When an agent cannot directly observe the opponent's position, it must infer it from history. We explored two approaches:

7.3.1 Particle Filters (S90)

A particle filter represents the belief as a set of weighted samples (particles):

$$b(s) \approx \sum_{i=1}^{N} w_i \cdot \delta(s - s_i)$$

Each particle is a hypothesis about the opponent's state. The filter:

  1. Predicts: Propagate particles forward using dynamics
  2. Updates: Reweight by observation likelihood
  3. Resamples: Replace low-weight particles with high-weight copies

We implemented a BeliefTracker with 200 particles (S90). The tracker output a belief vector that was concatenated with the observation.

7.3.2 BiMDN (G&I 2024)

The Bidirectional Mixture Density Network (BiMDN) is a learned belief representation:

  • An LSTM encoder processes the agent's observation history
  • The encoder outputs parameters of a Gaussian mixture
  • The mixture represents the belief over opponent state

The BiMDN is trained jointly with the policy using the negative log-likelihood of the true opponent state:

$$L_{\text{BiMDN}} = -\log p(s_{\text{opp}} | \text{history})$$

Critical implementation detail: The BiMDN needs a warm-up period (10,000 steps in G&I config) before its outputs are reliable. During warm-up, the agent uses ground-truth opponent positions. This warm-up was initially missing in our reproduction and caused poor performance (S95 fix #2).

7.4 Our Belief-State Self-Play Experiment

In S90, we integrated the BeliefTracker into the training loop:

  1. Evader maintains a particle-filter belief over pursuer state
  2. Belief is concatenated with observation
  3. Policy network takes (obs + belief) as input

The belief tracker worked but did not prevent collapse. The key finding: drift is structural, not curriculum-induced. Even with perfect belief, the competitive dynamics still push toward collapse.

7.5 Masking Curriculum (S75)

Inspired by PO-GRL (Partial Observation curriculum learning), we tried annealing the observation difficulty:

  1. Start: Full observability (omnidirectional, infinite range)
  2. Anneal: Gradually reduce FOV angle and range
  3. End: Final FOV (120°, 6m for pursuer)

Result: +10–15 percentage points improvement before the run was killed by a disk-full restart (S75).
